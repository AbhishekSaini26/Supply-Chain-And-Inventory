# Supply Chain & Inventory Checks Dashboard (Power BI)

## 📌 Project Overview
This project provides an interactive Power BI dashboard designed to monitor logistics performance, warehouse order distribution, delivery delays, and inventory flow across multiple suppliers and regions.

## 📊 Key Business Metrics & Insights
- **Total Order Volume:** Analyzed **689+** unique orders[cite: 2].
- **Total Units Handled:** Evaluated **90K+** items across warehouse locations[cite: 2].
- **Delivery Delays:** Tracked and flagged **245** delayed shipments to identify logistics bottlenecks[cite: 2].
- **In-Transit Inventory:** Monitored **104** active shipments to ensure SLA compliance[cite: 2].
- **Average Delivery Time:** Calculated an average fulfillment cycle of **6.57 days**[cite: 2].

## 🛠️ Tools & Technologies Used
- **Business Intelligence:** Power BI (Power Query, DAX, Custom Tooltips)[cite: 2]
- **Data Source:** CSV / Excel Dataset
- **Key DAX Functions:** `SUM`, `COUNT`, `AVERAGE`, Custom Filter Measures

## 💡 Key Features
1. **Logistics Performance Tracking:** Monthly and yearly breakdowns of order volumes and shipment modes[cite: 2].
2. **Supplier & Warehouse Slicers:** Interactive dynamic filtering by suppliers (e.g., Alpha Supplies, Beta Components) and warehouse nodes (Noida, Greater Noida, Delhi)[cite: 2].
3. **Product Inventory Distribution:** Categorical breakdown of product quantities and stock levels[cite: 2].
